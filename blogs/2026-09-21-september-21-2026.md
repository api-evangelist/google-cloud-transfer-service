Feature Storage Transfer Service now supports filtering Amazon S3 source objects by storage class. You can specify a list of storage classes to include when creating or updating transfer jobs using the Google Cloud console, the gcloud CLI, or the REST API. For more information, see Filter source objects by storage class .
