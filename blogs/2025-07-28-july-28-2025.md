Feature Storage Transfer Service agent-based transfers now support Cloud Storage regional endpoints . When you specify a Cloud Storage regional endpoint for a transfer agent, all data transfer traffic through that agent to or from a Cloud Storage bucket remains within the specified Google Cloud region. See Regional endpoints for details.
